# Code of Conduct

This project aims to provide a respectful and safe space for users, contributors, and maintainers.

GitHub documents `CODE_OF_CONDUCT.md` as one of the repository community health files, and a code of conduct helps contributors understand in advance what behavior is expected in the project.

## Our standard

Participants are expected to:

- communicate respectfully,
- give constructive technical feedback,
- stay open to questions and different experience levels,
- focus discussions on the project and its improvement,
- help maintain a professional and inclusive environment.

## Unacceptable behavior

The following behavior is not acceptable:

- harassment, threats, or personal attacks,
- discriminatory or hateful language,
- repeated hostile or dismissive responses,
- sharing private information without permission,
- intentionally disruptive behavior.

## Scope

This code of conduct applies to all repository spaces, including:

- issues,
- pull requests,
- reviews,
- discussions,
- documentation contributions.

## Reporting

If you experience or witness unacceptable behavior, contact the maintainers privately when possible and include enough context for review.

## Enforcement

Maintainers may edit, hide, lock, or remove content that violates this code of conduct, and may restrict participation when necessary to protect the project and its contributors.

## Reference

This file is a lightweight project-specific conduct policy. If the project later needs a more formal standard wording, the Contributor Covenant is a common reference used by many repositories.
