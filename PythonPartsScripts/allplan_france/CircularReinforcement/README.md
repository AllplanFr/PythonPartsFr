# CircularReinforcement | ALLPLAN FRANCE PythonParts Collection

`CircularReinforcement` is a PythonPart for ALLPLAN that helps create circular reinforcement.

## What this asset does

This PythonPart creates parametric circular arcs that can be converted into reinforcement within ALLPLAN using `Convert, Match Elements`.

## Where to find it

After installation, the asset is available in the ALLPLAN Library under:

`Office` → `ALLPLAN FRANCE` → `CircularReinforcement`

## How to use it

1. Open the ALLPLAN Library.
2. Navigate to `Office` → `ALLPLAN FRANCE`.
3. Start `CircularReinforcement`.
4. Fill in the parameters in the PythonPart property palette.
5. Validate the creation in the drawing.

## Requirements

- ALLPLAN 2026 or newer
